# About this site

I'm a student who started making study guides for my friends before exams, and they found them useful enough that I built this site so anyone in our courses can use them.

## How the guides are made

I draft each guide with an AI assistant (Claude), then review and edit it against my own course notes before posting. I check the definitions, formulas and every worked answer. Even so, mistakes can slip through, so treat these as a study aid, not an official source.

This site isn't affiliated with my school or any professor. The guides don't reproduce lecture slides, textbook passages or past exams.

## Spot a mistake?

Found an error, or want a guide on a topic that isn't here yet? Open an issue on the [GitHub repository](https://github.com/barr-studiesguelph/study-guides/issues) and I'll take a look.

## How it's built

This site is built with [Zensical](https://zensical.org), a static site generator, and hosted for free on GitHub Pages. Every guide is a Markdown file, and the site rebuilds and publishes itself automatically whenever I add or change one.
