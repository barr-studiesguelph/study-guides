The three rules

Chain rule. d/dx f(g(x)) = f′(g(x)) · g′(x). Derivative of the outside, keep the inside, times the derivative of the inside.

  • d/dx e3x² = e3x² · 6x = 6x e3x²
  • d/dx ln(x² + 5) = 1x² + 5 · 2x = 2xx² + 5
  • d/dx sin(5x) = 5 cos(5x)

Product rule. (fg)′ = f′g + fg′. Example: d/dx x² sin x = 2x sin x + x² cos x.

Quotient rule. (f/g)′ = f′g − fg′g². Example: d/dx xx + 1 = (x + 1) − x(x + 1)² = 1(x + 1)².

Common mistakes

  • Using the power rule on eˣ or 2ˣ. The power rule needs a variable base and a constant exponent.
  • Forgetting the inside derivative: d/dx e2x is 2e2x, not e2x.
  • Differentiating a product piece by piece: (x²eˣ)′ is not 2x·eˣ.
  • Writing ln(a + b) = ln a + ln b. There is no law for the log of a sum.

  2. Outside: ½(x² + 1)−1/2. Inside derivative: 2x.

Quotient rule with top eˣ and bottom x.

  2. = (eˣ·x − eˣ·1)/x².

§ 7.1

Implicit Differentiation & Applications

Step 1 Learn the idea

Some curves, like x³ + y³ = 6xy, cannot be solved for y. You can still find dy/dx: differentiate both sides with respect to x and treat y as a function of x. Every time you differentiate something with y in it, the chain rule attaches a y′.

Rule: every y-term gets × y′

Termd/dx
x³3x²
y³3y² · y′
xyy + x y′ (product rule)
sin ycos y · y′
eyey · y′
ln yy′ / y

Method

  1. Differentiate both sides with respect to x. Put y′ on every y-term.
  2. Move all y′ terms to one side, everything else to the other.
  3. Factor out y′.
  4. Divide to get y′ alone.

Applications

  • Slope at a point: plug in both x and y.
  • Tangent line: y − y₁ = m(x − x₁).
  • Normal line: slope −1/m (perpendicular).
  • Second derivative: differentiate y′ again (quotient rule), then replace any y′ with its formula.

Worked example

Find the tangent line to x³ + y³ = 6xy at (3, 3).

  1. Check the point: 27 + 27 = 54 and 6·3·3 = 54. ✓
  2. Differentiate: 3x² + 3y² y′ = 6y + 6x y′.
  3. Collect: 3y² y′ − 6x y′ = 6y − 3x².
  4. Factor and divide: y′ = (6y − 3x²)/(3y² − 6x) = 2y − x²y² − 2x.
  5. At (3, 3): y′ = (6 − 9)/(9 − 6) = −1.
  6. Tangent: y − 3 = −1(x − 3), so y = −x + 6.

Common mistakes

  • Forgetting y′ on a y-term (writing d/dx y³ = 3y²).
  • Skipping the product rule on xy.
  • Plugging in only x when the slope formula also has y.
  • Using −m instead of −1/m for the normal line.

E1 Find the tangent line to ey + xy = e at (0, 1).

Hint

d/dx ey = ey y′, and xy needs the product rule.

Show full solution
  1. Check: e¹ + 0 = e. ✓

  3. Factor: y′(ey + x) = −y, so y′ = −y/(ey + x).

Hint

  1. y′ = −x/y.
  2. y″ = −(1·y − x·y′)/y² (quotient rule).
  3. Replace y′: y″ = −(y − x(−x/y))/y² = −(y + x²/y)/y².
  4. Multiply top and bottom by y: y″ = −(y² + x²)/y³.
  5. Use the curve: x² + y² = 25.

Answer: y″ = −25/y³

Common mistake: Leaving y′ inside the answer instead of substituting −x/y.

§ 7.2

Logarithmic Differentiation

Step 1 Learn the idea

The power rule needs a constant exponent. The aˣ rule needs a constant base. When the variable is in both the base and the exponent (xˣ, xsin x), neither rule works. Taking ln of both sides brings the exponent down so you can use the product rule. The same trick turns a messy product or quotient into a sum.

When to use it

  • Variable in base and exponent: xˣ, xsin x, (ln x)ˣ.
  • Long products or quotients: (x + 1)²(x − 3)⁴/(x² + 5).

Key fact: d/dx ln y = y′y (chain rule).

Method

  1. Take ln of both sides.
  2. Use log laws to bring exponents down and split products.
  3. Differentiate both sides. The left side is y′/y.
  4. Multiply both sides by y.
  5. Replace y with the original function.

Worked example

Differentiate y = xˣ (x > 0).

  1. ln y = ln(xˣ) = x ln x.
  2. Differentiate: y′/y = 1·ln x + x · (1/x) = ln x + 1.
  3. Multiply by y: y′ = y(ln x + 1).
  4. Substitute: y′ = xˣ(ln x + 1).

Technical note: if y could be negative, take ln|y|. Since d/dx ln|y| = y′/y too, you get the same formula.

Common mistakes

  • Using the power rule on xˣ and getting x·xˣ⁻¹.
  • Stopping at y′/y = … and forgetting to multiply by y.
  • Leaving y in the final answer instead of the original function.
  • Writing ln(a·b) = ln a · ln b.

§ 7.3

Related Rates

Step 1 Learn the idea

In a related rates problem, several quantities change over time and are tied together by one equation. Treat everything as a function of t, differentiate the equation with respect to t, and solve for the rate you want.

The golden rule

Differentiate first, plug in after. If you plug in x = 6 before differentiating, x becomes a constant and its rate disappears.

Method

  1. Draw and label. Use numbers only for things that never change; give changing things letters.
  2. List the given rates and the wanted rate, with signs. Decreasing means negative.
  3. Write an equation linking the quantities.
  4. Differentiate with respect to t (chain rule: d/dt x² = 2x · dx/dt).
  5. Substitute the values at that instant. Find any missing value from the original equation.
  6. Solve, give units, and answer in a sentence.

Formulas you may need

ShapeFormula
CircleA = πr², C = 2πr
SphereV = (4/3)πr³, S = 4πr²
ConeV = (1/3)πr²h
CylinderV = πr²h
Right trianglex² + y² = z²
Similar trianglesmatching sides in equal ratios, e.g. r/h = 4/10

Worked example

A 10 m ladder leans on a wall. The bottom slides away at 1 m/s. How fast is the top sliding down when the bottom is 6 m from the wall?

  1. Let x = distance from wall to bottom, y = height of top. Given dx/dt = 1. Want dy/dt when x = 6.
  2. Equation: x² + y² = 100 (the ladder length 10 is constant).
  3. Differentiate: 2x · dx/dt + 2y · dy/dt = 0.
  4. Missing value: when x = 6, y = √(100 − 36) = 8.
  5. Substitute: 2(6)(1) + 2(8) dy/dt = 0, so dy/dt = −12/16 = −3/4.
  6. The top slides down at 3/4 m/s (dy/dt = −3/4 m/s).

Common mistakes

  • Plugging in x = 6 before differentiating.
  • Wrong sign on a decreasing quantity.
  • Forgetting the chain rule: d/dt r² = 2r · dr/dt.
  • No units, or answering a different rate than the one asked.

§ 8.1

Horizontal & Vertical Tangents, Fermat, Rolle, MVT

Step 1 Learn the idea

A tangent is horizontal where the slope is 0 and vertical where the slope blows up. The theorems in this section say when a function must have a point with a certain slope.

Horizontal and vertical tangents

  • Horizontal: dy/dx = 0. For a fraction, numerator = 0 and denominator ≠ 0.
  • Vertical: denominator = 0 and numerator ≠ 0. For y = f(x): f continuous at a and f′(x) → ±∞ (e.g. x1/3 at 0).
  • Both 0: inconclusive. Investigate further.

The theorems

Fermat. If f has a local max or min at c and f′(c) exists, then f′(c) = 0. The converse is false: x³ has f′(0) = 0 but no extremum.

Rolle. If f is continuous on [a, b], differentiable on (a, b), and f(a) = f(b), then there is c in (a, b) with f′(c) = 0.

Mean Value Theorem (MVT). If f is continuous on [a, b] and differentiable on (a, b), then there is c in (a, b) with f′(c) = f(b) − f(a)b − a. In words: at some moment the instant rate equals the average rate.

Write-up template (copy this on the test)

  1. f is continuous on [a, b] because … (polynomial, root of a nonnegative quantity, etc.).
  2. f is differentiable on (a, b) because …
  3. (Rolle only) f(a) = … = f(b).
  4. "By the Mean Value Theorem (or Rolle's Theorem), there exists c ∈ (a, b) such that …"
  5. Solve for c and check that c is in (a, b).

Worked example

Find the horizontal and vertical tangents of x² + xy + y² = 3.

  1. Differentiate: 2x + y + x y′ + 2y y′ = 0, so y′ = −(2x + y)/(x + 2y).
  2. Horizontal: 2x + y = 0, so y = −2x. Substitute: x² − 2x² + 4x² = 3x² = 3, x = ±1. Points (1, −2) and (−1, 2). Denominators: 1 − 4 = −3 ≠ 0 ✓.
  3. Vertical: x + 2y = 0, so x = −2y. Substitute: 4y² − 2y² + y² = 3y² = 3, y = ±1. Points (−2, 1) and (2, −1). Numerators ≠ 0 ✓.
  4. Horizontal at (1, −2), (−1, 2). Vertical at (−2, 1), (2, −1).

Worked example

Find c from the MVT for f(x) = x³ − x on [0, 2].

  1. f is a polynomial, so it is continuous on [0, 2] and differentiable on (0, 2).
  2. Average rate: (f(2) − f(0))/(2 − 0) = (6 − 0)/2 = 3.
  3. f′(c) = 3c² − 1 = 3, so c² = 4/3 and c = ±2/√3.
  4. Only c = 2/√3 ≈ 1.155 is in (0, 2). c = 2/√3.

Common mistakes

  • Forgetting to check that the denominator isn't also 0.
  • Using MVT or Rolle without stating the hypotheses.
  • Keeping a value of c that is outside (a, b).
  • Thinking f′(c) = 0 guarantees a max or min.

Step 4 Exam-level

Get every concept check right before this step.

E1 Show that x³ + 3x + 1 = 0 has exactly one real root.

Hint

Two parts. Existence: IVT. Uniqueness: suppose two roots and use Rolle to get a contradiction.

Show full solution
  1. Let f(x) = x³ + 3x + 1, a polynomial, so continuous and differentiable everywhere.
  2. Existence: f(−1) = −3 < 0 and f(0) = 1 > 0. By the IVT there is a root in (−1, 0).
  3. Uniqueness: suppose there were two roots a < b. Then f(a) = f(b) = 0, so by Rolle's Theorem some c ∈ (a, b) has f′(c) = 0.
  4. But f′(x) = 3x² + 3 ≥ 3 > 0 for all x. Contradiction.
  5. So there is exactly one real root.

Answer: Exactly one root, in (−1, 0)

Common mistake: Proving only that a root exists. 'Exactly one' needs the uniqueness argument too.

§ 8.2

Increasing vs Decreasing

Step 1 Learn the idea

The sign of f′ tells you whether f goes up or down. Positive slope: the graph rises. Negative slope: it falls.

Increasing Function Theorem

On an interval I:

  • f′ > 0 on I ⇒ f is increasing on I.
  • f′ < 0 on I ⇒ f is decreasing on I.
  • f′ = 0 on I ⇒ f is constant on I.

Why: by the MVT, f(b) − f(a) = f′(c)(b − a). If f′(c) > 0 and b > a, then f(b) > f(a).

Method

  1. Find the domain.
  2. Find f′ and factor it.
  3. Split points: where f′ = 0, where f′ is undefined, and any gaps in the domain.
  4. Sign chart: test one x in each interval.
  5. State the intervals.

Worked example

Where is f(x) = x³ − 3x² − 9x + 1 increasing or decreasing?

  1. Domain: all reals. f′(x) = 3x² − 6x − 9 = 3(x − 3)(x + 1).
  2. Split points: x = −1, 3.
  3. Sign chart:
    Interval(−∞, −1)(−1, 3)(3, ∞)

    x − 3−−+
    f′+−+
    f↗ inc↘ dec↗ inc
  4. Increasing on (−∞, −1) and (3, ∞). Decreasing on (−1, 3).

Common mistakes

  • Confusing f′ > 0 (rising) with f > 0 (above the axis).
  • Using zeros of f as split points instead of zeros of f′.
  • Joining intervals across a point not in the domain.
  • Forgetting where f′ is undefined.

§ 8.3

Critical & Extreme Points

Step 1 Learn the idea

Maxima and minima can only happen where the slope is 0 or undefined. Find those spots, then test each one.

Definitions and tests

Critical number: c in the domain of f with f′(c) = 0 or f′(c) undefined.

First derivative test at a critical number c:

  • f′ changes + to − : local max.
  • f′ changes − to + : local min.
  • No sign change: neither.

Second derivative test when f′(c) = 0:

  • f″(c) > 0 : local min (cup).
  • f″(c) < 0 : local max (cap).
  • f″(c) = 0 : test fails. Use the first derivative test.

Closed interval method (absolute max/min on [a, b]): evaluate f at every critical number in (a, b) and at both endpoints. Biggest wins, smallest loses.

Worked example

Find the local extrema of f(x) = x³ − 3x² − 9x + 1.

  1. f′ = 3(x − 3)(x + 1), critical numbers −1 and 3.
  2. f″ = 6x − 6.
  3. f″(−1) = −12 < 0 ⇒ local max. f(−1) = −1 − 3 + 9 + 1 = 6.
  4. f″(3) = 12 > 0 ⇒ local min. f(3) = 27 − 27 − 27 + 1 = −26.
  5. Local max (−1, 6), local min (3, −26).

Common mistakes

  • Calling a point with f″ = 0 an inflection point or an extremum without checking.
  • Forgetting critical numbers where f′ is undefined.
  • Mixing up the signs: f″ > 0 is a min (cup), not a max.
  • On a closed interval, forgetting to check the endpoints.

§ 8.4

Concavity

Step 1 Learn the idea

Concavity is about how the graph bends. Concave up is a cup that holds water; concave down is a cap that spills it.

Concavity

  • f″ > 0: concave up. Slopes are increasing; tangent lines lie below the graph.
  • f″ < 0: concave down. Slopes are decreasing; tangent lines lie above.
  • Inflection point: a point on the graph where concavity changes. Candidates: f″ = 0 or f″ undefined. You must check the sign changes, and the point must be in the domain.

Increasing and concave up are different things. e−x is decreasing and concave up.

Method

  1. Find f″ and factor it.
  2. Split points: f″ = 0, f″ undefined, domain gaps.
  3. Sign chart for f″.
  4. State concave up/down intervals. Inflection points where the sign changes and f is defined; give both coordinates.

Worked example

Concavity of f(x) = x³ − 3x² − 9x + 1.

  1. f″ = 6x − 6 = 6(x − 1).
  2. x < 1: f″ < 0, concave down. x > 1: f″ > 0, concave up.
  3. Sign changes at x = 1, f(1) = 1 − 3 − 9 + 1 = −10.
  4. CD on (−∞, 1), CU on (1, ∞), inflection point (1, −10).

Common mistakes

  • Calling every f″ = 0 point an inflection point.
  • Giving only the x-value of an inflection point.
  • Mixing up 'increasing' (f′) and 'concave up' (f″).
  • Missing points where f″ is undefined.

Curve Sketching

Step 1 Learn the idea

Sketching puts all of chapter 8 together. Work through the checklist, collect the facts, then draw.

Checklist

  1. Domain.
  2. Intercepts. x = 0 for the y-intercept; f = 0 for x-intercepts.

  6. f″: concavity, inflection points.

§ 9.2

Optimization

Step 1 Learn the idea

Optimization is a word problem that ends in a max or min. The calculus is short. Most of the work is setting up a function of one variable.

Method

  1. Draw a picture.
  2. Name the objective (what to max/min) and the variables.
  3. Write the constraint (the fixed quantity).
  4. Use the constraint to write the objective in one variable.
  5. State the domain.
  6. Set the derivative = 0 and solve.
  7. Justify max or min: closed interval method, first derivative test, or second derivative test.
  8. Answer exactly what was asked, with units.

Worked example

A farmer has 2400 ft of fence for a rectangle along a river. The river side needs no fence. Find the largest area.

  1. Let x = each side perpendicular to the river, y = the side parallel. Objective: A = xy.
  2. Constraint: 2x + y = 2400, so y = 2400 − 2x.
  3. One variable: A(x) = x(2400 − 2x) = 2400x − 2x², domain 0 < x < 1200.
  4. A′ = 2400 − 4x = 0 ⇒ x = 600. Then y = 1200.
  5. A″ = −4 < 0, so this is a max.
  6. 600 ft by 1200 ft, area 720,000 ft².

Common mistakes

  • Differentiating with two variables still in the objective.
  • Mixing up objective and constraint.
  • Finding x but not answering the question asked (e.g., the area).
  • No justification that the critical point is a max or min.

§ 9.3

Linear Approximation

Step 1 Learn the idea

Close to a point, a smooth curve looks like its tangent line. So you can estimate a hard value, like √4.1, using the tangent line at an easy nearby point, like 4.

Linear approximation

L(x) = f(a) + f′(a)(x − a). This is the tangent line at x = a.

  • Pick a near x where f(a) and f′(a) are easy.
  • Concave up near a ⇒ L underestimates. Concave down ⇒ L overestimates.
  • Differentials: dy = f′(x) dx estimates the change in y.
  • Trig: angles must be in radians. 1° = π/180.

Worked example

Estimate √4.1.

  1. f(x) = √x, a = 4. f(4) = 2, f′(x) = 1/(2√x), f′(4) = 1/4.
  2. L(x) = 2 + (1/4)(x − 4).
  3. L(4.1) = 2 + 0.1/4 = 2.025.
  4. f″ < 0 (concave down), so this is an overestimate. Actual: 2.02485.

Common mistakes

  • Using f′(x) instead of f′(a) in the formula.
  • Choosing a = the number you're trying to find.
  • Using degrees in trig approximations.
  • Mixing up over/under: concave down means the tangent is above the curve.

P1 Estimate ∛27.3. Is it an over- or underestimate?

Hint

a = 27, f(x) = x1/3, f′(x) = (1/3)x−2/3.

Show full solution
  1. f(27) = 3. f′(27) = (1/3)(27)−2/3 = 1/(3 · 9) = 1/27.
  2. L(27.3) = 3 + (1/27)(0.3) = 3 + 0.0111 = 3.0111.
  3. f″ = −(2/9)x−5/3 < 0 at 27: concave down ⇒ overestimate. Actual 3.01107.

Answer: ≈ 3.0111, an overestimate

Common mistake: Computing 27−2/3 as 1/3 instead of 1/9.

P2 Find the linearization of ln x at a = 1 and estimate ln 1.05.

Hint

f(1) = 0, f′(1) = 1.

Show full solution
  1. L(x) = 0 + 1 · (x − 1) = x − 1.
  2. ln 1.05 ≈ 0.05.
  3. f″ = −1/x² < 0 ⇒ overestimate. Actual 0.04879.

Answer: L(x) = x − 1; ln 1.05 ≈ 0.05 (overestimate)

Common mistake: Writing L(x) = x (forgetting f(1) = 0 and the − a).

E1 Estimate (1.01)10.

Hint

f(x) = x10, a = 1.

Show full solution
  1. f(1) = 1, f′(x) = 10x⁹, f′(1) = 10.
  2. L(1.01) = 1 + 10(0.01) = 1.1.
  3. f″ = 90x⁸ > 0 ⇒ underestimate. Actual 1.1046.

Answer: ≈ 1.1 (underestimate)

Common mistake: Using a = 0 or treating 1.01¹⁰ as 1.01 · 10.

E2 A sphere's radius is measured as 10 cm with possible error ±0.1 cm. Estimate the maximum error in the volume.

Hint

V = (4/3)πr³. Use dV = V′(r) dr.

Show full solution
  1. dV = 4πr² dr.
  2. = 4π(100)(0.1) = 40π.

Answer: dV = 40π ≈ 125.7 cm³ (about 3% of V)

Common mistake: Using dr = 10 or forgetting to square r.

E3 Estimate tan 44°.

Hint

Use a = 45° = π/4. Convert −1° to radians: −π/180.

Show full solution
  1. f(π/4) = tan(π/4) = 1. f′ = sec² x, f′(π/4) = (√2)² = 2.
  2. Δx = −1° = −π/180.
  3. L = 1 + 2(−π/180) = 1 − π/90 ≈ 0.9651.
  4. tan is concave up on (0, π/2) ⇒ underestimate. Actual 0.9657.

Answer: ≈ 1 − π/90 ≈ 0.9651 (underestimate)

Common mistake: Using Δx = −1 (degrees) and getting 1 − 2 = −1.
