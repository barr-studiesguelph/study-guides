Five rules that cost marks when forgotten

  1. ε is given, δ is built. Every ε–δ proof starts “Let ε > 0.” and δ may depend only on ε (and a), never on x.
  2. Any restriction on x in your scratch work must go inside δ. That is what the min is for: δ = min{1, ε/K}.
  3. K is the largest value of the extra factor on the restricted interval. If the factor is in a denominator, bound it from below, away from 0.
  4. IVT/EVT: name the function, say “continuous on [a, b] because …”, show the values, cite the theorem by name, and finish with “there exists c ∈ (a, b) …”.
  5. Closed interval method checks the endpoints too. Critical numbers inside (a, b) plus f(a) and f(b), then compare.

Part 1

Making assumptions in limit proofs

The order of the lines is the logic. ε first, then δ, then x.

Template · ε–δ limit

Definition. limx→a f(x) = L means: for every ε > 0 there is a δ > 0 such that 0 < |x − a| < δ ⇒ |f(x) − L| < ε.

Let ε > 0. ← arbitrary, you don't choose it
Choose δ = ______ . Then δ > 0. ← you choose it, from ε only
Suppose 0 < |x − a| < δ. ← the only thing you know about x
Then … so |f(x) − L| < ε. ← reached, never assumed
Therefore limx→a f(x) = L. ∎

Part 2

What goes in the brackets of δ = min{…}

Each wrong option comes with a specific ε and x that break it, so you can see the failure instead of taking it on trust.

Template · the min recipe

  1. Factor. Write |f(x) − L| = |x − a| · |g(x)|.
  2. Restrict. Assume |x − a| < 1. Use ½ instead if 1 would let a denominator reach 0 or leave the domain.
  3. Bound. On that interval find K with |g(x)| < K. Take the largest |g| can be. If g is a fraction, its denominator gets its smallest size.
  4. Solve. |x − a| · K < ε whenever |x − a| < ε/K.
  5. Combine. δ = min{1, ε/K}. Now both restrictions hold at once.

Worked: limx→3 x² = 9

|x² − 9| = |x − 3| · |x + 3|
|x − 3| < 1 ⇒ 2 < x < 4 ⇒ 5 < x + 3 < 7 ← use 7, the top
7 |x − 3| < ε ⇔ |x − 3| < ε/7
δ = min{1, ε/7}

Why min and not max: |x − a| < min{p, q} gives |x − a| < p and |x − a| < q. A max only guarantees one of them.

Part 3

Writing EVT & IVT answers

Most lost marks come from skipped lines, not wrong maths. Learn the template, spot the gaps in other people's answers, then write your own and mark it against the rubric.

Template · IVT

Theorem. If f is continuous on [a, b] and N is strictly between f(a) and f(b), then there exists c ∈ (a, b) with f(c) = N.

  1. Let g(x) = … (move everything to one side if x appears on both sides).
  2. g is continuous on [a, b] because … (polynomial, sum/product/quotient with non-zero denominator, composition).
  3. g(a) = … < 0 and g(b) = … > 0.
  4. So 0 is between g(a) and g(b).
  5. By the Intermediate Value Theorem, there exists c ∈ (a, b) such that g(c) = 0, so [original equation] holds at x = c.

Template · EVT

Theorem. If f is continuous on a closed, bounded interval [a, b], then f attains an absolute max and an absolute min on [a, b].

  1. f is continuous on [a, b] because …, so by the EVT f has an absolute max and min there.
  2. Find f′(x). Critical numbers: f′(c) = 0 or f′(c) does not exist.
  3. Keep only critical numbers inside (a, b).
  4. Evaluate f at those and at both endpoints.
  5. Largest value is the absolute max, smallest is the absolute min. Give the value and every x where it occurs.

Continuity at a

f is continuous at a when all three hold: f(a) is defined, limx→a f(x) exists, and the two are equal.

Derivative from the definition

f′(x) = limh→0 [f(x + h) − f(x)] / h ← combine, cancel h, then let h → 0
